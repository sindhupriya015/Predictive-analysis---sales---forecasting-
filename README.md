# Predictive Analytics Using Historical Data

## Project Overview
This project uses Python and Machine Learning to analyze historical sales data and forecast future sales trends.

## Objective
To build a predictive model that learns from historical data, evaluates prediction accuracy, and estimates future sales.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Linear Regression

## Project Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Historical sales visualization
4. Feature engineering
5. Training and testing data split
6. Linear Regression model training
7. Model evaluation using MAE, RMSE, and R²
8. Future sales forecasting
9. Visualization of actual and predicted sales

## Results
The model produces predictions for a test period and forecasts sales for the next 12 months. Evaluation metrics are used to understand its performance.

## Dataset
The current version uses simulated monthly sales data for demonstration and learning purposes. It does not represent real company sales.

## How to Run
1. Open the notebook in Google Colab.
2. Run each code cell in order.
3. Review the evaluation metrics, graphs, and forecast.
4. Download the generated CSV files if needed.

## Conclusion
This project demonstrates how Python and Machine Learning can help analyze trends and forecast future sales to support data-driven decisions.
